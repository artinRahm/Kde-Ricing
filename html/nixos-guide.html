NixOS KDE Plasma Ricing Guide

Declarative, reproducible KDE Plasma ricing on NixOS using Flakes and Home Manager

~50 min read Advanced NixOS

1. Why NixOS for Ricing?

NixOS brings a fundamentally different approach to system configuration that's perfect for ricing:

Declarative Configuration

Your entire system state (packages, services, configs) is defined in code. No manual changes that get lost.

Atomic Rollbacks

Every change creates a new generation. Boot into previous generations instantly if something breaks.

Reproducible Builds

Same config = identical system. Share your rice as a git repo; others get exactly your setup.

Home Manager

Manage user-level config (dotfiles, plasma config, themes) declaratively alongside system config.

Learning Curve: NixOS requires learning the Nix language and its ecosystem. Expect a steeper initial investment but massive long-term payoff for ricing.

2. NixOS Installation

2.1 Download & Boot

Download the NixOS ISO (Plasma/KDE variant recommended) from nixos.org.

# Write to USB (replace sdX)
sudo dd if=nixos-plasma-*.iso of=/dev/sdX bs=4M status=progress && sync

2.2 Partition (UEFI Example)

# Using disko (declarative partitioning) - recommended
# Or manual with fdisk/cfdisk

# Manual example:
cfdisk /dev/nvme0n1
# Create: EFI (1G, type EFI), Root (rest, Linux filesystem)

mkfs.fat -F32 /dev/nvme0n1p1
mkfs.btrfs -L nixos /dev/nvme0n1p2

# Mount with subvolumes (btrfs)
mount /dev/nvme0n1p2 /mnt
btrfs subvolume create /mnt/@
btrfs subvolume create /mnt/@home
btrfs subvolume create /mnt/@nix
btrfs subvolume create /mnt/@log
btrfs subvolume create /mnt/@snapshots
umount /mnt

mount -o subvol=@,compress=zstd,noatime /dev/nvme0n1p2 /mnt
mkdir -p /mnt/{home,nix,var/log,.snapshots,boot}
mount -o subvol=@home,compress=zstd,noatime /dev/nvme0n1p2 /mnt/home
mount -o subvol=@nix,compress=zstd,noatime /dev/nvme0n1p2 /mnt/nix
mount -o subvol=@log,compress=zstd,noatime /dev/nvme0n1p2 /mnt/var/log
mount -o subvol=@snapshots,compress=zstd,noatime /dev/nvme0n1p2 /mnt/.snapshots
mount /dev/nvme0n1p1 /mnt/boot

2.3 Generate Initial Config

nixos-generate-config --root /mnt --no-filesystems

# Edit configuration.nix
nano /mnt/etc/nixos/configuration.nix

2.4 Minimal configuration.nix

{ config, pkgs, ... }:

{
  imports = [ ./hardware-configuration.nix ];

  boot.loader.systemd-boot.enable = true;
  boot.loader.efi.canTouchEfiVariables = true;

  networking.hostName = "nixos-rice";
  networking.networkmanager.enable = true;

  # Enable flakes
  nix.settings.experimental-features = [ "nix-command" "flakes" ];

  # KDE Plasma
  services.xserver.enable = true;
  services.xserver.displayManager.sddm.enable = true;
  services.xserver.desktopManager.plasma6.enable = true;

  # Graphics (choose one)
  # hardware.opengl.enable = true;  # Intel/AMD
  # services.xserver.videoDrivers = [ "nvidia" ];  # NVIDIA

  # User
  users.users.youruser = {
    isNormalUser = true;
    extraGroups = [ "wheel" "networkmanager" "video" ];
    packages = with pkgs; [ git vim ];
  };

  # Allow unfree (for NVIDIA, codecs, etc.)
  nixpkgs.config.allowUnfree = true;

  system.stateVersion = "24.05";
}

2.5 Install & Reboot

nixos-install --root /mnt --flake /mnt/etc/nixos#nixos-rice
# Or without flakes initially:
# nixos-install --root /mnt

reboot

3. Flakes: Modern NixOS Configuration

3.1 Flake Structure

# Create flake structure
mkdir -p ~/nixos-config/{hosts,modules,home,overlays}
cd ~/nixos-config
git init
nixos-config/ ├── flake.nix ├── flake.lock ├── hosts/ │ └── desktop/ │ ├── configuration.nix │ └── hardware-configuration.nix ├── modules/ │ ├── kde.nix │ ├── graphics.nix │ ├── audio.nix │ └── theming.nix └── home/ ├── home.nix └── programs/

3.2 flake.nix

{
  description = "NixOS KDE Rice Configuration";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-24.05";
    home-manager = {
      url = "github:nix-community/home-manager/release-24.05";
      inputs.nixpkgs.follows = "nixpkgs";
    };
    plasma-themes = {
      url = "github:EliverLara/Nordic-kde";
      flake = false;
    };
    # Add more theme repos as needed
  };

  outputs = { self, nixpkgs, home-manager, plasma-themes, ... }@inputs:
    let
      system = "x86_64-linux";
      pkgs = nixpkgs.legacyPackages.${system};
      lib = nixpkgs.lib;
    in {
      nixosConfigurations.desktop = nixpkgs.lib.nixosSystem {
        system = system;
        modules = [
          ({ pkgs, ... }: {
            imports = [ ./hosts/desktop/configuration.nix ];
            nixpkgs.config.allowUnfree = true;
          })
          home-manager.nixosModules.home-manager
          {
            home-manager.useGlobalPkgs = true;
            home-manager.useUserPackages = true;
            home-manager.sharedModules = [ ./home/home.nix ];
          }
        ];
      };
    };
}

4. KDE Plasma Configuration (modules/kde.nix)

{ config, pkgs, ... }:

{
  # Enable Plasma 6
  services.xserver.enable = true;
  services.xserver.displayManager.sddm.enable = true;
  services.xserver.desktopManager.plasma6.enable = true;

  # Wayland session
  services.xserver.desktopManager.plasma6.wayland = true;

  # Essential packages
  environment.systemPackages = with pkgs; [
    plasma6.packages.plasma-browser-integration
    plasma6.packages.kde-gtk-config
    plasma6.packages.kwin
    plasma6.packages.kvantum
    plasma6.packages.kvantum-qt5
    plasma6.packages.kvantum-qt6
    plasma6.packages.kdeconnect
    plasma6.packages.plasma-workspace
    plasma6.packages.systemsettings
    plasma6.packages.konsole
    plasma6.packages.dolphin
    plasma6.packages.kwrite
    plasma6.packages.firefox
    # Ricing tools
    plasma6.packages.latte-dock
    plasma6.packages.krohnkite
    plasma6.packages.bismuth
  ];

  # KDE Global config via systemd user services
  systemd.user.services.plasma-config = {
    description = "Apply KDE Plasma configuration";
    wantedBy = [ "plasma-workspace.target" ];
    serviceConfig = {
      Type = "oneshot";
      Environment = [ "DISPLAY=:0" ];
    };
    script = ''
      ${pkgs.plasma6.packages.kwriteconfig6}/bin/kwriteconfig6 \
        --file kdeglobals --group General --key Font "Noto Sans,10,-1,5,50,0,0,0,0,0"
      ${pkgs.plasma6.packages.kwriteconfig6}/bin/kwriteconfig6 \
        --file kdeglobals --group General --key Fixed "JetBrains Mono,10,-1,5,50,0,0,0,0,0"
      ${pkgs.plasma6.packages.plasma-apply-colorscheme}/bin/plasma-apply-colorscheme Nordic
      ${pkgs.plasma6.packages.kvantummanager}/bin/kvantummanager --set Nordic
    '';
  };

  # Enable PipeWire
  services.pipewire = {
    enable = true;
    alsa.enable = true;
    alsa.support32Bit = true;
    pulse.enable = true;
    jack.enable = true;
  };
  security.rtkit.enable = true;
}

5. Home Manager: Declarative User Config

5.1 home/home.nix

{ config, pkgs, ... }:

{
  home.username = "youruser";
  home.homeDirectory = "/home/youruser";
  home.stateVersion = "24.05";

  # Enable programs
  programs.git.enable = true;
  programs.vim.enable = true;
  programs.zsh.enable = true;
  programs.bash.enable = true;

  # Fonts

    noto-fonts
    noto-fonts-emoji

    ttf-firacode-nerd
    ttf-cascadia-code-nerd

  # Plasma config files

    source = ./plasma/kdeglobals;
  };

  home.file.".config/kwinrc" = {
    source = ./plasma/kwinrc;
  };

  home.file.".config/kvantum/kvantum.kvconfig" = {
    source = ./plasma/kvantum.kvconfig;
  };

  # Plasma applets layout

    source = ./plasma/plasma-appletsrc;

  # Color schemes
  home.file.".local/share/color-schemes/Nordic.colors" = {
    source = ./plasma/colors/Nordic.colors;

  # KWin scripts
  home.file.".local/share/kwin/scripts/krohnkite" = {

    source = ./plasma/latte/my-layout.layout.latte;
  };

  # Environment variables
  home.sessionVariables = {
    QT_QPA_PLATFORMTHEME = "kde";
    QT_STYLE_OVERRIDE = "kvantum";
    EDITOR = "nvim";
    VISUAL = "nvim";
  };

  # Packages
  home.packages = with pkgs; [
    neovim
    btop
    fastfetch
    fd
    ripgrep
    fzf
    zoxide
    direnv
    # Ricing tools
    plasma6.packages.plasmastyle
  ];
}

6. Declarative Theming

6.1 Custom Theme Module (modules/theming.nix)

{ config, pkgs, ... }:

let
  # Custom theme package
  nordic-theme = pkgs.stdenv.mkDerivation {
    name = "nordic-kde-theme";
    src = pkgs.fetchFromGitHub {
      owner = "EliverLara";
      repo = "Nordic-kde";
      rev = "v4.0";
      sha256 = "sha256-...";
    };
    dontBuild = true;
    installPhase = ''
      mkdir -p $out/share/plasma/look-and-feel
      cp -r Nordic $out/share/plasma/look-and-feel/
    '';
  };

  catppuccin-theme = pkgs.fetchFromGitHub {
    owner = "catppuccin";
    repo = "kde";
    rev = "v1.0.0";
    sha256 = "sha256-...";
  };
in {
  environment.systemPackages = [ nordic-theme catppuccin-theme ];

  # Apply theme via systemd user service
  systemd.user.services.apply-theme = {
    description = "Apply KDE Global Theme";
    wantedBy = [ "plasma-workspace.target" ];
    after = [ "plasma-workspace.target" ];
    serviceConfig = {
      Type = "oneshot";
      Environment = [ "DISPLAY=:0" "DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus" ];
    };
    script = ''
      ${pkgs.plasma6.packages.plasma-apply-lookandfeel}/bin/plasma-apply-lookandfeel -a "Nordic"
    '';
  };
}

8. System Maintenance

8.1 Updating

# Update flake inputs
cd ~/nixos-config
nix flake update

# Rebuild system
sudo nixos-rebuild switch --flake .#desktop

# Or with Home Manager
home-manager switch --flake .#youruser@desktop

8.2 Generations & Rollback

# List generations
sudo nix-env --list-generations --profile /nix/var/nix/profiles/system

# Rollback to previous generation
sudo nixos-rebuild switch --rollback

# Or boot into previous generation from systemd-boot menu

8.3 Garbage Collection

# Remove old generations (keep last 30 days)
sudo nix-collect-garbage --delete-older-than 30d

# Optimize store
nix store optimise

8.4 Backup Strategy

# Your entire config is in git!
cd ~/nixos-config
git add .
git commit -m "Update rice: new theme, keybindings"
git push

# To restore on new machine:
git clone https://github.com/you/nixos-config
cd nixos-config
sudo nixos-rebuild switch --flake .#desktop
