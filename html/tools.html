Everything you need to rice KDE Plasma like a pro

Essential Packages

Core KDE Packages

Arch Linux

pacman -S plasma-meta konsole dolphin \
    firefox systemsettings kde-gtk-config \
    sddm plasma-wayland-session \
    kvantum-qt5 kvantum-qt6 \
    kdeconnect plasma-browser-integration \
    xdg-desktop-portal-kde

NixOS

environment.systemPackages = with pkgs; [
    plasma6.packages.plasma-browser-integration
    plasma6.packages.kde-gtk-config
    plasma6.packages.kvantum
    plasma6.packages.kvantum-qt5
    plasma6.packages.kvantum-qt6
    plasma6.packages.kdeconnect
  ];

Theming Engines

Kvantum Qt theming engine with SVG-based themes pacman -S kvantum-qt5 kvantum-qt6
Plasma Style (plasmastyle) CLI tool for applying global themes yay -S plasmastyle
KDE GTK Config Sync GTK themes with KDE color scheme pacman -S kde-gtk-config

Docks & Panels

Latte Dock Modern, configurable dock with plasma integration yay -S latte-dock-git
Plasma Panels Built-in, highly customizable panels Included in plasma-workspace
KDE Connect Phone integration, notifications, clipboard sync pacman -S kdeconnect

KWin Tiling Scripts

Krohnkite i3-like dynamic tiling for KWin yay -S krohnkite-git
Bismuth Automatic tiling with flexible layouts yay -S bismuth-git
Polonium Keyboard-driven window management yay -S kwin-script-polonium-git

CLI Ricing Tools

kwriteconfig6 / kwriteconfig5 Write KDE config files from command line Included in plasma-workspace
kreadconfig6 / kreadconfig5 Read KDE config values Included in plasma-workspace
plasma-apply-colorscheme Apply color schemes globally Included in plasma-workspace
plasma-apply-lookandfeel Apply global themes Included in plasma-workspace
kvantummanager Manage Kvantum themes pacman -S kvantum-qt5 kvantum-qt6
qdbus / dbus-send Interact with KDE via D-Bus pacman -S qt6-tools

Backup & Sync Tools

Git (Bare Repo) Version control for dotfiles pacman -S git
Stow Symlink farm manager for dotfiles pacman -S stow
Home Manager Declarative user config (NixOS/Arch) Via Nix
Timeshift System snapshots & rollback pacman -S timeshift

Configuration Files Reference

~/.config/kdeglobals

Main KDE settings: fonts, colors, UI behavior, shortcuts

~/.config/kwinrc

Window manager: borders, effects, rules, tiling

~/.config/plasma-org.kde.plasma.desktop-appletsrc

Panel layout, widgets, wallpapers, containment

~/.config/kglobalshortcutsrc

Global keyboard shortcuts

~/.config/kwinrulesrc

Window-specific rules (position, size, desktop)

~/.config/kvantum/kvantum.kvconfig

Kvantum theme settings

~/.local/share/color-schemes/

Custom color scheme files (.colors)

~/.local/share/plasma/look-and-feel/

Global theme packages

~/.local/share/kwin/scripts/

KWin script installations
